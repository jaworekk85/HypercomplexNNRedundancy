## Conventions that matter (learned the hard way)

- Frozen sources are hash-checked. Earlier studies store SHA-256 of their sources
  (`protocol.json`, `summary.json`), and re-running them raises if those files changed.
  Do NOT edit `src/cnn_training.py`, `scripts/cifar_cnn.py`, `scripts/multisource_compensation.py`,
  `src/compression/internal_merging.py`, etc. Add new modules instead. Example:
  `scripts/eurosat_cnn.py` reuses the frozen trainer by pointing `scripts.cifar_cnn.make_model`
  at the four-band factory instead of editing the trainer.
- Each study writes `protocol.json` and refuses to run if config/sources changed; use a new
  output folder for a changed protocol.
- Prespecify policies, removal levels and hyperparameters in `configs/` BEFORE outcomes. No
  official-test inference anywhere so far (CIFAR test was used by early pilots; EuroSAT test
  split of 5,400 images is untouched).
- Random rows: average repetitions within training seed first, then SD across seeds. Report
  paired per-seed effects including unfavorable seeds.
- Quaternion layout: component-blocked channels [all r, all i, all j, all k];
  `component_indices(kept, units)` maps units to scalar channels.
- `scripts/summarize_research.py` regenerates `docs/RESEARCH_STATUS.md` and appends interpretation
  blocks to some REPORT.md files; new studies get their own section there.
